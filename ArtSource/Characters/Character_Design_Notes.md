# 캐릭터 디자인 요소 정리

Unity Aim Combat Slice · 2026-11-14

정면·오른쪽 측면·후면 3면도를 기준으로 정리했다. 좌우는 캐릭터 본인 기준이며, 화면 방향이 필요한 경우 따로 표기했다.

## 공통 표현

- 서 있는 전신은 약 5등신. 세 방향의 머리 높이, 어깨, 허리, 발바닥 기준선을 맞춘다.
- 굵은 검정 외곽선과 경계가 선명한 셀 음영을 쓴다. 흰 배경에서 후광과 외곽 번짐 없이 실루엣이 읽히게 한다.
- 복장과 손의 형태가 보이도록 기준 시트는 무장 없이 구성한다.

## Rapid

사용자가 확정한 Rapid 3면도 기준.

| 부위 | 디자인 |
|---|---|
| 헤어·얼굴 | 연보랏빛 은발 숏컷. 바깥으로 뻗는 뒷머리와 턱선을 감싸는 옆머리. 자홍색 눈과 이를 살짝 드러낸 미소. |
| 머리핀 | 오른쪽 관자놀이의 사선 청록 두 줄 핀. 정면에서 화면 왼쪽에 보인다. |
| 상의 | 몸에 맞는 짧은 차콜 재킷. 청록 테두리의 스탠드 카라가 V자로 내려와 가슴 중앙 지퍼와 만나며, 지퍼는 재킷 밑단까지 이어진다. V 안으로 짙은 이너가 보인다. |
| 하네스·벨트 | 밝은 회색 어깨 스트랩 두 줄, 짙은 몸통 가로 밴드, 밝은 회색 허리 벨트. 등판의 밝은 회색 가로 연결판에 둥근 리벳 두 개. |
| 위팔·장갑 | 검정 테두리의 청록 위팔 패치. 측면에서는 가로로 더 길게 보인다. 팔꿈치 아래의 말린 소매 끝에 청록 띠가 있고, 아래팔 일부가 드러난다. 차콜색 반장갑. |
| 하의·장식 | 양쪽 허벅지에 플랩 주머니가 달린 넉넉한 차콜 카고 팬츠. 왼쪽 앞 허리에 청록 매듭과 술, 작은 노란 구슬. |
| 부츠 | 둥근 앞코와 두꺼운 밑창. 발목마다 청록 띠 두 줄. |

## Charge

Charge 3면도 수정본 기준.

| 부위 | 디자인 |
|---|---|
| 헤어·얼굴 | 짙은 회보라 머리, 비스듬한 앞머리와 턱선까지 내려오는 뾰족한 옆머리. 보라색 눈과 입을 다문 진지한 표정. |
| 포니테일·리본 | 머리 뒤 높은 위치에서 묶은 크고 각진 포니테일. 머리 다발 사이로 선명한 보라색 리본이 내려온다. 후면에서 화면 왼쪽, 정면에서 화면 오른쪽으로 흐른다. |
| 상의 | 차콜색 상의와 스탠드 카라. 보라색 라인이 카라에서 가슴 중앙을 지나 허리 벨트 위까지 이어져 닫힌 앞섶을 표현한다. 가슴 볼륨과 스트랩의 곡선은 정면과 측면에 반영한다. |
| 하네스·벨트 | 회색 어깨 스트랩과 차콜 가로 밴드. 어깨와 허리에 은회색 사각 테두리 버클. 후면의 세로 스트랩 두 줄은 코트 밑단 가까이까지 내려온다. |
| 소매·장갑 | 짧은 겉소매 끝에 넓은 보라색 띠. 손목까지 밀착되는 차콜색 안소매와 손가락을 덮는 장갑. |
| 코트·하의 | 앞이 갈라진 무릎 길이 코트. 앞섶부터 둥근 밑단까지 보라색 테두리. 안에는 발목으로 갈수록 좁아지는 차콜 바지. |
| 부츠 | 둥근 앞코와 얕은 밑창 홈. 발목마다 보라색 띠 두 줄. |

## Shotgun

Shotgun 3면도 카고 파우치 보완본 기준.

| 부위 | 디자인 |
|---|---|
| 헤어·얼굴 | 구리빛이 도는 적갈색 숏컷. 한쪽으로 쓸린 굵은 앞머리와 볼 옆까지 뾰족하게 내려오는 옆머리. 끝이 바깥으로 뻗고 안쪽 층은 어둡게 보인다. 붉은 눈과 입을 다문 표정. |
| 상의 | 차콜색 스탠드 카라 재킷. 검은 중앙 지퍼가 목부터 허리까지 내려온다. 몸에 맞는 상의와 볼륨 있는 소매를 조합한다. |
| 하네스·등판 | 어깨를 타고 내려오는 짙은 스트랩 두 줄. 상체 앞뒤에 은회색 사각 버클. 어깨 윗부분의 주황 포인트와 등판의 굵은 주황 가로 띠. |
| 위팔·장갑 | 검정 테두리와 짙은 짧은 표시가 들어간 주황 위팔 패치. 팔꿈치 근처에서 걷은 소매 아래로 맨 아래팔이 드러난다. 짙은 손목 밴드와 손가락을 덮는 차콜 장갑. |
| 벨트·탄약 파우치 | 분할선이 있는 차콜 허리 벨트와 정면의 사각 버클. **오른쪽 뒤 허리**에 파우치 한 개. 금색 테두리의 붉은 샷건 탄피형 소품 세 개가 바깥에 보이고, 아래로 긴 주황 스트랩 하나가 늘어진다. 정면에서는 화면 왼쪽, 후면에서는 화면 오른쪽에 보인다. |
| 팬츠·카고 포켓 | 발목으로 갈수록 좁아지는 넉넉한 차콜 팬츠. 양쪽 허벅지 바깥에 카고 포켓. 플랩과 하단에 주황 띠가 있고 중간은 차콜색이다. 오른쪽 포켓 일부는 늘어진 스트랩에 가려진다. |
| 부츠 | 둥근 앞코, 두꺼운 차콜 밑창. 발목마다 넓은 주황 띠 한 줄. |
