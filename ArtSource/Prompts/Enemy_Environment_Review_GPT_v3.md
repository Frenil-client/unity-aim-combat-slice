# 보스 부위 파괴 제작 검토 v3

1. 소켓은 교체 메시마다 복제하지 말고 본체에 고정한다. A-E의 피벗, 로컬 축, 결합면 규격을 공유하고 소켓 바깥의 메시만 교체하면 위치 튐과 중복 면을 줄일 수 있다. 그림의 일치는 제작 규격 검증을 대신하지 못하므로 3D 제작 때 좌표를 확인한다.
2. A와 B는 각각 판 3장을 하나의 파괴 모듈로 묶는다. 손상 단계에서는 바깥 장갑 일부만 제거해 검은 내부 프레임을 드러내고, 파괴 단계에서는 프레임까지 제거한다. 날개 전체가 사라지는 단계와 혼동하지 않게 남은 실루엣을 충분히 유지한다. A는 화면 왼쪽으로 통일한다.
3. D의 두 판은 하나의 모듈로 취급하되 본체의 코어 틀과 분리한다. 온전 상태에서도 코어의 중앙 적색 면이 읽히게 하고, 파괴 시 노출 면적이 확실히 넓어지게 한다. 손상 발광과 절단면은 코어보다 어둡게 유지한다.
4. C와 E는 판 하나가 빠진다는 규칙을 그대로 적용하기 어렵다. 손상 시 외장 한쪽을 크게 깨뜨리고 내부 축을 남기며, 파괴 시 짧은 밑동만 남기는 방식이 더 명확하다. 쐐기 홈 2-3개를 크게 만들고 작은 균열은 생략한다.
5. 체력 구간은 온전 50% 초과, 손상 0% 초과 50% 이하, 파괴 0%로 경계를 명확히 하는 편이 좋다. 메시 전환 시 기존 콜라이더도 함께 바꾸고, 파괴된 부위의 피격 판정은 끈다. 전투 기능 확정이나 코드 변경은 이번 작업 범위에 포함하지 않는다.
6. 각 단계는 같은 정면 카메라와 본체 크기로 비교한다. 파편 4-6개는 순간 효과로만 사용하고 소켓이나 코어를 가리지 않게 한다. 실제 플레이 크기에서는 형태 변화와 상단 상태 칸을 함께 사용하고, 도해의 정렬은 추후 모델 피벗 검증으로 보완한다.
